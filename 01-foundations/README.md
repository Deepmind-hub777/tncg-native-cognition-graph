# 01 — Foundations

This section defines TNCG's scope and conceptual foundations.

Planned work:
- Definitions: native semantic world, concept, sense, pragmatic context, partial equivalence, cognitive transfer
- Theory review: multilingual conceptual representation, cross-linguistic influence, translanguaging, and cognitive development
- Research questions: operational questions and falsifiable hypotheses

TNCG distinguishes a language's native semantic structure, relations between concepts across languages, and an individual learner's developing representation. These layers are related but should not be collapsed.
