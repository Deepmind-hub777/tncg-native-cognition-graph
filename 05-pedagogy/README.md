# 05 — Pedagogy

TNCG learning applications are organized across three settings:

- **School TNCG:** curriculum-linked inquiry, PBL, and subject learning
- **Family TNCG:** intergenerational dialogue and shared exploration
- **Lifelong TNCG:** continuing development, reflection, and knowledge transmission

Student-facing experiences should make concepts understandable without requiring learners to navigate complex graph structures. The graph is primarily a reasoning and instructional support layer.
