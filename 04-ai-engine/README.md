# 04 — AI Reasoning Engine

This section specifies technical components that may support TNCG.

- **GraphRAG:** retrieval over language-specific and cross-language subgraphs
- **WSD:** word-sense disambiguation using context and usage evidence
- **Knowledge tracing:** language-specific tracking of learner understanding
- **HITL:** human review for semantic conflicts and culturally sensitive annotations
- **Auditability:** provenance, versioning, confidence, and traceable changes

The system must not infer mastery in one language solely from performance in another. AI-generated annotations remain proposals until reviewed under a documented quality process.
