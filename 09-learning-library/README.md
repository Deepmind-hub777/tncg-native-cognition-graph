# 09 — TNCG Learning Library

This section stores reusable learning materials generated for the TNCG program.

## Collections

- `daily-trilingual-stories/` — daily bilingual/trilingual story lessons, adult and children's tracks
- `adult-thai-speaking-workshops/` — adult Thai speaking practice, role-play, corrections, and review notes

## Archival rules

1. Preserve the complete learner-facing material, not merely a short summary.
2. Record the date, sequence number where applicable, theme, language level, and version.
3. Keep adult and children's tracks clearly separated.
4. Preserve Thai script, translations, pronunciation aids, dialogue, exercises, and answer keys when present.
5. Record sources and distinguish scripture, documented history, cultural tradition, and teaching adaptation.
6. Do not publish identifiable learner details, private conversations, or sensitive information.
7. If a session contains personal speaking attempts, archive only the teaching content and generalized learning notes unless explicit permission is given for more.
8. Use stable filenames and avoid overwriting earlier lessons; corrections should be versioned or committed as a new revision.
