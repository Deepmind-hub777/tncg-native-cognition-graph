# Daily Trilingual Stories

Daily TNCG story lessons for families learning Thai and exploring Scripture, church history, mission history, and Thai / Southeast Asian contexts.

## File convention

`YYYY-MM-DD-day-NN-short-topic.md`

Each daily file should contain:
- Adult track
- Children's track
- Chinese, Thai, and English story text
- Thai vocabulary and usable sentence patterns
- Pronunciation support where useful
- Speaking practice and role-play
- Scripture references and faith theme
- Historical and cultural context with sources
- Family or community practice
- TNCG concept map
- Comprehension questions and speaking challenge

Keep source-language wording and distinctions intact. Mark paraphrases and simplified learner versions clearly.
