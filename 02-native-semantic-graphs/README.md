# 02 — Native Semantic Graphs

Language-specific resources belong in:
- `chinese/` — Chinese concepts, senses, usage, and contexts
- `thai/` — Thai concepts, senses, usage, and contexts
- `english/` — English concepts, senses, usage, and contexts

Cross-language links should express the type and strength of a relation: contextual match, partial overlap, analogy, contrast, or non-equivalence. A cross-language link must never overwrite the source-language definition.
